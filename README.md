# Мій стек — трекер добавок (PWA)

Щоденний трекер прийому добавок і БАДів з обліком запасів. Працює офлайн, встановлюється
на головний екран телефона. React 18 + Vite, без бекенда — усі дані живуть у `localStorage`.

## Можливості

- **Сьогодні** — навігація по днях, кільце прогресу, серія 🔥 без пропусків, банер «Час докупити»,
  чекбокси за групами часу прийому, «Відмітити все одразу».
- **Облік запасів** — відмітка прийому зменшує запас на дозу; toast-попередження, коли лишається ≤ 7 днів.
- **Стек** — редагування добавок (час прийому, доза, одиниця, залишок), перейменування, додавання,
  видалення з підтвердженням, поповнення упаковки.
- **Історія** — список відмічених днів; тап відкриває день.
- **Статистика** — 7 днів: загальний %, днів без пропусків, бар-чарт, рейтинг пропусків.
- **Дані** — експорт/імпорт JSON (бекап на випадок, якщо `localStorage` злетить), очищення історії.

## Локальний запуск

```bash
npm install
npm run dev
```

Відкрий адресу, яку покаже Vite (зазвичай http://localhost:5173).

## Білд і прев'ю

```bash
npm run build      # збирає у dist/
npm run preview    # локальний сервер на віддачі dist/ (тут працює service worker)
```

## Іконки PWA

Іконки (`public/icons/icon-192.png`, `icon-512.png`) уже згенеровано. Щоб перегенерувати:

```bash
npm run icons
```

## Деплой на Vercel

Статичний сайт, без серверних функцій.

1. Залий репозиторій на GitHub і підключи його у Vercel (**Add New → Project**).
2. Vercel сам визначить Vite. Якщо ні, вкажи вручну:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
3. **Deploy**.

Або через CLI:

```bash
npm i -g vercel
vercel          # перший деплой (прев'ю)
vercel --prod   # у продакшн
```

## Як додати на головний екран телефона

**Android (Chrome):** відкрий сайт → меню `⋮` → **Встановити застосунок** / **Додати на головний екран**.

**iOS (Safari):** відкрий сайт → кнопка «Поділитися» → **На екран «Додому»**.

Після встановлення застосунок відкривається на весь екран і працює офлайн (статика й шрифти кешуються
service worker'ом).

## Структура

```
/
├── index.html
├── vite.config.js          # vite-plugin-pwa + manifest
├── public/icons/           # 192 і 512 px, maskable
├── scripts/gen-icons.mjs   # генератор іконок (без залежностей)
└── src/
    ├── main.jsx
    ├── App.jsx             # таб-бар, перемикання вкладок (без react-router)
    ├── styles.css          # усі стилі й дизайн-токени
    ├── store/              # reducer + селектори + Context
    ├── lib/                # storage / dates / i18n
    └── components/         # TodayView, ProgressRing, HistoryView, StatsView, StackView, ConfirmButton, Toast
```

## Дані

Зберігаються у `localStorage` під ключем `supptracker-v1`. Якщо сховище недоступне, застосунок
працює у пам'яті до перезавантаження (попереджає про це у вкладці «Стек»). Регулярно роби
**Експорт у файл** — це твій бекап.
